# AWS CLI Basics Cheatsheet

## Who Am I

```bash
aws sts get-caller-identity
```

## List S3 Buckets

```bash
aws s3 ls
```

## Copy Files To S3

```bash
aws s3 cp local-file.txt s3://bucket-name/path/
```

## Sync A Folder

```bash
aws s3 sync ./folder s3://bucket-name/folder/
```

## CloudWatch Log Groups

```bash
aws logs describe-log-groups
```

## Tail Logs

```bash
aws logs tail /aws/lambda/function-name --follow
```

## ECS Clusters

```bash
aws ecs list-clusters
aws ecs list-services --cluster cluster-name
```

## Debug Checklist

- Confirm account and region first.
- Check IAM permissions before assuming service issues.
- Use logs and metrics together.
- Keep production commands read-only unless the action is intentional.
