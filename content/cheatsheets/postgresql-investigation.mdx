# PostgreSQL Investigation Cheatsheet

## Connect

```bash
psql -h host -U user -d database
```

## List Databases And Tables

```sql
\l
\dt
\d table_name
```

## Count Rows

```sql
select count(*) from table_name;
```

## Recent Rows

```sql
select *
from table_name
order by created_at desc
limit 20;
```

## Check Indexes

```sql
select indexname, indexdef
from pg_indexes
where tablename = 'table_name';
```

## Active Queries

```sql
select pid, state, query
from pg_stat_activity
where state != 'idle';
```

## Table Size

```sql
select pg_size_pretty(pg_total_relation_size('table_name'));
```

## Debug Checklist

- Check whether the query uses the expected index.
- Verify row counts before and after migration jobs.
- Inspect slow or active queries.
- Compare application filters with database filters.
